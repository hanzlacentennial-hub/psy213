# Chapter 4 Practice Quiz

A free React + TypeScript quiz built from 19 shared study flashcards.

## Run locally

1. Install Node.js (18+).
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev` and open the local URL shown.

## Publish

Run `npm run build` and deploy the `dist` folder to a static host such as Cloudflare Pages. No backend required.

## Content

Edit `src/data.ts` to add or correct questions. The three distractors for each card were drafted for practice; review them against course materials before sharing widely. Get the original card creator's permission before redistributing their content.
